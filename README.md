# Планировщик билда — Divinity: Original Sin 2 (Definitive Edition)

**Открыть: <https://imarshev.github.io/dos2-build-planner/>** — работает в браузере на
компьютере и телефоне, без установки, аккаунта и сервера; интерфейс русский и английский.

Неофициальный фан-проект: статический сайт, который считает всё по правилам игры —
сколько очков стоит очко характеристики, что даёт предмет и как из этого складывается урон.

## Возможности

**Персонаж**
- Происхождение (6 канонических + «свой персонаж»), раса (5), уровень 1–22 — очки пулов
  по официальной level-системе DE.
- 6 атрибутов, гражданские и боевые умения — со стоимостью очка, остатком пула и
  производными характеристиками (бонусы экипировки и талантов уже учтены).
- Экипировка по 10 слотам + сумка для неэкипируемого; таланты — обычные, родовые и квестовые.
- Секции перетаскиваются мышью, порядок сохраняется; билд автосохраняется в браузере.

**Урон**
- Оружие: `среднее(мин, макс) × (1 + школа%) × (1 + атрибут% + владение%)` — +10 %/очко
  школы, +5 %/очко профиля выше 10, +5 %/очко владения (Two-Handed / Single-Handed / Ranged).
- Заклинания: к 100 unit базы множитель `1 + (INT − 10)×5 % + школа×10 %`; уровень школы
  берётся итоговый, с аффиксами «+ к школе» и удвоением Lone Wolf.
- Формулы сверены по игровым тултипам и Fextralife; динамику боя (высота, бафф в бою)
  калькулятор не предсказывает — он считает статы листа персонажа.

**База предметов и «Кузница редкости»**
- 254 предмета DE, из них 104 оружия; поиск по названию, зоне и навыку; фильтры по редкости,
  слоту, типу оружия, зоне, уровню, плюс «даёт навык», «с координатами», «только DE».
- Координаты находок на карте, требования, урон, броня, цена, описания — с русскими
  названиями из официального русского пака игры (198/254 ≈ 78 % покрытия).
- «Кузница редкости»: генерация Divine/Legendary-предметов со случайными аффиксами
  (Divine = 5 бросков … Uncommon = 1) по слоту, тиру и уровню.

**Навыки**
- Слоты памяти = атрибут «Память» + половина уровня + «Эрудит»; стоимость навыка — его точки
  памяти. Не хватило памяти или требований — навык снимается сам, с подписью, чего не хватило.
- Во вкладке «Навыки» выезжающей панели — база навыков: поиск по названию, школе и источнику,
  фильтры по школе, тиру, памяти и источнику; недоступные помечены, чего именно не хватает.

**Обмен билдами**
- Экспорт билда в JSON и импорт из файла — чтобы показать сборку другому игроку.

## Данные

Источники — игровые паки Definitive Edition и LSOF-файлы уровней (парсеры в `tools/`),
сверка по вики: [Fextralife](https://divinityoriginalsin2.wiki.fextralife.com/),
[dos2.wiki](https://dos2.wiki/), [divinity.fandom.com](https://divinity.fandom.com/);
русские имена — из официального RU-пака. Ход исследований — в `docs/research/`
(закрытые — в `docs/research/archive/`), в дистрибутив попадает только собранная витрина.

Числа: 254 предмета · 104 оружия · 198 русских названий (78 %) — `node tools/data_query.js --stats`
на 2026-11-05; 65 предметов с координатами — аудит LSOF 2026-10-31.

Игровые данные и названия — © Larian Studios. Проект некоммерческий, рекламы и
сбора данных нет.

## Технологии и структура

Vanilla JS, сборки нет: `app/js/app/*.js` — 13 скриптов UI (порядок загрузки = порядок
ответственностей, страж `app/qa/app_split.js`), `app/js/data.js` — витрина, которую
генерирует `app/build_data.js` из `data/*.json`. Из библиотек только `i18next` (RU/EN),
`js-yaml` (словари `app/i18n/*.yaml`) и `Sortable` (перетаскивание секций).

```
app/        index.html, css/, js/, i18n/, qa/ — сам планировщик
data/       items.json, character.json, ru_* — исходные данные для сборки
deploy/     публикация на GitHub Pages (deploy/README.md)
docs/       контекст проекта, исследования, дизайн-паттерны
tools/      парсеры LSOF/pak, аудиты данных, снимки интерфейса
```

## Запуск и проверка локально

```powershell
node app/build_data.js      # пересобрать app/js/data.js из data/
node app/serve.js           # http://127.0.0.1:8091
node app/qa/run_all.js      # 40 проверок (2026-11-10)
node app/qa/mobile_layout.js   # вёрстка 360/390 px, 29 проверок
```

Приёмка интерфейса — пикселями: `node tools/shots/shoot.js --url http://127.0.0.1:8091/index.html
--out X --size 1440x900` (+1280x800, вторая локаль — `--lang en`) со сверкой SHA256 по эталонам
`tools/shots/baseline/`, и тап-флоу телефоном — `node tools/shots/mobile_flow.js --url …`.
Шаги приёмки — в навыке `dos2-ui-testing`, паттерны — `docs/design/patterns.md`.

## Деплой

Только через `deploy/deploy-pages.ps1`: гейт (сборка → `check_ids` → QA), состав дистрибутива,
push в публичный репозиторий-артефакт, проверка `VERSION.json` на живом сайте, слепок в
`deploy/releases/` + откат `rollback-pages.ps1`. Живой адрес —
<https://imarshev.github.io/dos2-build-planner/>; подробности — `deploy/README.md`.
